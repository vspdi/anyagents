# Security

Report vulnerabilities privately using GitHub private vulnerability reporting when enabled. Avoid posting credentials or exploit details in public issues.

The 0.1.x line is currently maintained. This CLI does not execute configured MCP servers or resolve their secrets; coding clients execute MCP commands, so review canonical configuration before use.

Release and publishing protections, their limitations, and owner setup are described in [docs/npm-publishing.md](docs/npm-publishing.md).
